# Ravrent Interactive — Studio Website

Static, dependency-free studio site featuring five projects: Ravrent Mechanic (private beta), Outmile, Motor Dynasty, Block Frontier and Life OS.

The production site is https://ravrentinteractive.vercel.app/ and the existing Vercel project ID is `prj_yQ4JXuJUnof3PJzS7I14f3rd3iu6`.

`index.html` contains the responsive site, accessibility controls, original CSS product exhibits and canvas-based animations. `icon.svg` provides an original favicon. `sw.js` retires stale caches from prior versions.

The site contains no API keys. Mechanic is presented without a public beta link until stronger access and rate-limit protections exist. All product illustrations are labeled design studies, not actual gameplay footage.

To enable future push-to-deploy workflows, connect the existing Vercel project to this GitHub repository from Vercel Settings → Git. Pushing source to GitHub does not by itself establish an automatic deployment connection.
